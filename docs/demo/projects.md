# Choose your next small discovery

These are original WireSnaps lessons. Each opens as a new personal project with
steps, an expected observation, a completion check and a suggested variation.
They are not copies of a manufacturer's numbered project book.

| --- | --- | --- |

## Six single-transistor projects

| One NPN | One PNP | Real purpose to investigate |
| --- | --- | --- |
| [Night Watch](../../?demo=npn-sensor#build) | [Sunrise Beacon](../../?demo=pnp-sensor#build) | A light responding automatically to the surroundings. |
| [Porch Timer](../../?demo=npn-timer#build) | [Courtesy Light](../../?demo=pnp-timer#build) | A light staying on briefly after a button is released. |
| [Desk Fan](../../?demo=npn-fan#build) | [Breeze Dial](../../?demo=pnp-fan#build) | A small control signal regulating a motor. |

These use ordinary component functions, documented reference values where
available and explicitly estimated model parameters. Match terminals and check
your actual kit manual before considering a physical build; the rendered layout
does not verify mechanical fit or safety.

## Four deliberate virtual failures

**Simulation only — do not try these with real components.** They open paused in
Experiment mode. Start the simulation deliberately; use Guided mode to compare
the intervention that prevents the predicted damage.

- [Filament Flash](../../?demo=break-bulb#build): an overpowered light bulb.
- [The Missing Resistor](../../?demo=break-led#build): excessive LED current.
- [One Load Too Many](../../?demo=break-npn#build): an overloaded NPN transistor.
- [The Stuck Motor](../../?demo=break-motor#build): a stalled motor heating up.
