These use ordinary component functions, documented reference values where available and explicitly estimated model parameters. Match terminals and check your actual kit manual before considering a physical build; the rendered layout does not verify mechanical fit or safety.

Four deliberate virtual failures

Simulation only — do not try these with real components. They open paused in Experiment mode. Start the simulation deliberately; use Guided mode to compare the intervention that prevents the predicted damage.

  • Filament Flash: an overpowered light bulb.
  • The Missing Resistor: excessive LED current.
  • One Load Too Many: an overloaded NPN transistor.
  • The Stuck Motor: a stalled motor heating up.
